# Code Signing Policy

## Project

**Ren'Py Toolkit** is a free and open-source Windows desktop application for Ren'Py visual novel developers.

Repository: https://github.com/GabffeeDev/definition-tool

## Code signing provider

**Free code signing provided by SignPath.io, certificate by SignPath Foundation.**

This project is applying for the SignPath Foundation open-source code-signing program. Acceptance and signing are subject to SignPath Foundation's current eligibility requirements and approval process.

## Maintainers and roles

**Committer / Author:** GabffeeDev  
**Reviewer:** GabffeeDev  
**Approver:** GabffeeDev

GabffeeDev controls and maintains the official source-code repository and is responsible for the project's releases.

If additional contributors receive commit access in the future, the project will maintain an appropriate review and approval process for code that is included in signed releases.

## Source-to-binary relationship

Official Windows binaries are built from the source code maintained in this repository. Releases are published through GitHub Releases.

When SignPath signing is enabled, signed binaries will be submitted through the applicable SignPath build, verification, and approval workflow. A release will only be signed after the required approval process has been completed.

## Privacy

This program will not transfer any information to other networked systems unless specifically requested by the user or the person installing or operating it.

Ren'Py Toolkit does not need to upload the user's Ren'Py project files to a remote server to perform its core functions.

## Security and release integrity

The project does not intentionally contain malware, potentially unwanted software, or functionality designed to evade Windows security mechanisms.

Users should obtain official binaries from the project's GitHub Releases and can inspect the corresponding source code in this repository.

## Authentication

Project maintainers with access to the repository and signing systems will use multi-factor authentication (MFA/2FA) where required by the applicable SignPath Foundation program terms.

## Changes to this policy

This policy may be updated when the project's signing workflow, maintainership, or SignPath Foundation requirements change.
